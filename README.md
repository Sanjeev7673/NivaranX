## Run

## Production
Connect the API route to the SNS Workbench orchestrator and keep credentials server-side.

## Safety
NIVARAN X is an awareness and grievance-navigation tool. It must not provide individualized investment recommendations, predict legal outcomes, promise compensation, or invent regulatory requirements.
